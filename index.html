Why this role is changing

  • AI will predict server load and automatically locate back-up servers.
  • Companies are shifting away from on-premise infrastructure toward cloud providers.
  • AI will automate real-time root cause analysis, so engineers focus on the harder issues.
  • Monitoring and issue resolution are merging with DevOps practices, like Infrastructure-as-Code.

Key trends driving this

🤖 AI & Analytics
☁️ Cloud Computing
🔀 Evolving IT Ecosystem

These three forces show up across all three role profiles below — each one leans more heavily on cloud, automation and security skills than the Infrastructure Support role does today.

Possible next role · Software & Applications track

DevOps Engineer

Moderate transition

Owns the build, release, deployment and configuration of applications as part of the agile team. Builds and runs the CI/CD pipeline, builds proof-of-concepts, and keeps pushing out tested, working releases.

Works closely with the business to gather requirements, builds and runs test plans, and fixes issues as they come up — usually in a fast-changing environment where priorities shift often. Comfortable with the org's programming languages, CI/CD tools, testing tools and configuration management tools.

Possible next role · Infrastructure track

SysOps Engineer

Moderate transition

Owns the reliability and efficiency of systems — optimising capacity and performance, using scripting to automate away recurring issues, and enabling infrastructure that scales. Also handles installs, upgrades, continuous monitoring, and keeping cloud platforms secure and compliant.

Strong in scripting and programming, comfortable with cloud platforms and scaling infrastructure. Works on-call and in shifts, prioritising well under pressure, and enjoys hands-on problem-solving with minimal supervision.

Possible next role · Cyber Security track

Senior Security Engineer / Security Engineer

Challenging transition

Designs, develops and implements secure system architectures — embedding security principles into system design to reduce risk from new technologies and business practices. Documents security standards and procedures, and reviews and audits infrastructure security systems.

Well-versed in cyber security standards, protocols and frameworks, and works in line with Singapore's Cyber Security Act 2018. Structured and systematic, articulate, and works well across teams and stakeholders.
